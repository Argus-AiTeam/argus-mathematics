# Root-character algebra: scope and proof

## Exact source and scope

The target is Lemma `tc:root-character` in the density manuscript,
`build/sections/06-traces.tex`, lines 652--751. The source expressly retains
nilpotents (lines 645--649). Here "reduced" means reduction modulo the
coefficient maximal ideal, not passage to a reduced ring.

The preceding Lemma `tc:trace-algebra` asserts that the class function satisfies
`t(1)=0` and

    t(x)t(y) = t(xy) + t(x/y).

The root-character lemma asserts, in matching parity, vanishing on all
nonroots; in opposite parity, vanishing on split elements and vanishing
of every product of two simple traces. In either parity it asserts that
every root trace squares to one.

These are assertions about the whole operator orbit, not just one Fourier
coefficient. The proposed finite-group theorem takes these identities as
hypotheses. It does not prove that the manuscript's modular constructions
satisfy them.

The algebraic conclusion is an order-two multiplicative character agreeing
with the trace on every element whose residual permutation is a 3-cycle.
The intermediate conclusion is factorization of the trace through a quotient
with elementary abelian residual kernel. Neither conclusion is a verification
of the pointwise 2-converse or either Goldfeld theorem.

Unramifiedness has a separate input: at a fixed stage the trace and residual
representation factor through a common finite quotient unramified outside
`S union U`. A character constructed on that quotient is unramified outside
the same support. Finite-group identities alone do not specify inertia or
prove the existence of this arithmetic quotient.

## Assumptions and excluded shortcuts

For source application we leave the coefficient-bound argument, the
characteristic-zero trace construction and its finite unramified quotient
as unverified manuscript inputs. They are not imported as established
arithmetic facts into the abstract algebra theorem.

Replacing the target algebra by its residue field is not a valid route:
in characteristic two, `1+epsilon` can be a nontrivial unit of order two
when `epsilon != 0` and `epsilon^2=0`. A bounded Jacobian multiplication
in `F_2[C_2]` tests precisely this phenomenon; it is not evidence for the
general root-character assertion.

No external classification or literature theorem is currently assumed in
the algebraic proof. In particular, existence of a normalizing
transposition lift must be proved, not assumed as the desired character
in disguise.

## Verification theorem

Let `G` be any group, `pi : G -> D_3` a homomorphism whose image contains
a rotation, and `A` any commutative ring of characteristic two. Let
`t : G -> A` be a class function satisfying the trace identity, split
vanishing, root-square identity and two-simple product vanishing above.
Then there is a homomorphism `alpha : G -> A^units` with

    alpha(g)^2 = 1 for every g,
    alpha(g) = t(g) whenever pi(g) is a 3-cycle.

No finiteness assumption on `G` is needed. The image of `pi` is necessarily
the rotation subgroup or all of `D_3`. This extends the finite-quotient
form of the source assertion, without strengthening its ring hypotheses.
It is a general proof, not an inference from the finite searches below.

### Proof

Let `K` be the subgroup generated by squares of elements in `ker(pi)`.
The trace identity applied to `x*u,u`, with `u` split, gives
`t(x*u^2)=t(x)`. Invariance is preserved under products and inverses.
Conjugates of kernel squares are kernel squares, so `K` is normal in `G`.
Thus `t` descends through `G/K`. Its residual kernel has exponent two;
any group of exponent two is abelian (invert a product).

For the remaining argument write `H` for this elementary kernel. If `g`
lifts `r 1`, then `g^3` lies in `H`, so `g^6=1`; `R=g^4` lifts `r 1`
and satisfies `R^3=1`. The trace identity with `1,R` gives
`t(R)=t(R^-1)`. With `R,R`, it gives
`t(R)^2=t(R^2)=t(R)`. The root-square hypothesis therefore gives `t(R)=1`.

For `a in H` set `beta(a)=t(a*R)`. Since `t(a)=0`, the identity with
`a,R` gives `t(a*R)=t(a*R^2)`. For `a,b in H`, the other term in
the trace product of `a*R,b*R` is split and vanishes. Put
`c=a*R*b*R^-1 in H`. Then

    beta(a) beta(b)
      = t(c*R^2) = t(c*R)
      = t(a*R*b) = t(b*a*R) = beta(a*b).

The penultimate equality is class invariance; the last uses commutativity
in `H`. Also `beta(a)^2=1`. Class invariance shows that `beta` is unchanged
by conjugation by `R`, so it kills the rotation commutators.

In the symmetric case take any lift `x` of `sr 0` and define

    a = x*R*x^-1*R,
    b = R^-1*a*R,
    c = R^-2*a*R^2,
    s = b*x.

All three of `a,b,c` lie in `H`. Since `a*R^-1=x*R*x^-1` has cube one,
`a*b*c=1`. Because `H` is abelian and `b^2=1`,

    s*R*s^-1 = b*a*c*R^-1 = R^-1.

This proves the normalizer-lift step constructively, including when
`s` has order four. Conjugacy and `t(a*R)=t(a*R^2)` show that `beta` is
also invariant under `s`. Both `s,s*R` are simple, so their trace product
is zero. Its trace identity is

    0 = t(s^2*R) + t(R) = beta(s^2) + 1.

Hence `beta(s^2)=1`, with no assumption that `s^2=1`.

Use the residual section `sigma(r i)=R^i` and
`sigma(sr i)=s*R^i`, for `i=0,1,2`. In the cyclic case only the first
three values are used. Set

    alpha(g) = beta(g*sigma(pi(g))^-1).

The section's multiplication defect is either `1` or `s^2`, and both
have beta-value one. Together with conjugation invariance of `beta`,
this proves multiplicativity of `alpha`. Its values square to one,
so they are units. On either root coset its value is the required trace.
Finally the quotient by its kernel has exponent two.

`Main.lean` implements this proof. For its internal working quotient
it uses the possibly larger invisible kernel, rather than `K` itself;
both the actual square-subgroup factorization and the normality and
exponent-two facts needed for that working quotient are proved there.

### Ramification statement

Suppose a continuous homomorphism from a Galois group to the finite
starting group kills inertia outside `S union U`. Composing the constructed
character with that homomorphism still kills these inertia groups.
It has finite image and is continuous. Its exponent-two quotient
corresponds to a rational elementary extension with the same support.
This is preservation of an input ramification bound, not a proof of
that bound for the manuscript's modular representations.

## Exact adversarial replay

`verify.py` uses exact arithmetic in `F_2[epsilon]/(epsilon^2)`, with
`epsilon != 0` and `(1+epsilon)^2=1`. It exhausts all class functions
with the necessary trace-value domains on six explicit groups, checking
every trace identity and reconstructing the character for every valid
function. It also checks group laws, residual maps, the square quotient,
the elementary kernel, and the explicit normalizer lift.

| Group | Order | Candidates | Valid opposite | Valid matching |
|---|---:|---:|---:|---:|
| `C3 x C4` | 12 | 256 | 2 | 2 |
| `C3 semidirect C4` | 12 | 16 | 1 | 1 |
| `S3 x C2` | 12 | 16 | 2 | 2 |
| `A4 x C2` | 24 | 16 | 2 | 2 |
| `S4 x C2` | 48 | 64 | 4 | 2 |
| `(Q8 semidirect C3) x C2` | 48 | 256 | 2 | 2 |

There are 624 candidate class functions and 13 valid traces. Six valid
traces have nontrivial root units. Two valid traces on `S4 x C2` have
nonzero nilpotent simple values, so the opposite-parity branch really
does test more than matching parity. The last group has a nonabelian
residual kernel and nontrivial rotation action; its square quotient is
nontrivial. The dicyclic model has order-four simple lifts.

These are finite adversarial tests, not the general proof. Their exact
counts and the bounded Jacobian diagnostic are serialized in
`exact_certificate.json`. The adapter discovery, inspected typed contract,
payload, version, protocol and exact output are retained as dedicated JSON
files. Jacobian supplied only the nilpotent multiplication diagnostic.
