# Result 20000582

## Moving-window Engel Hilbert cocycles with $\Omega(\sqrt{k})$ homogeneous gauge distortion

**Status:** independently reviewed construction theorem (Tier-B infrastructure)<br>
**Field:** metric geometry and bi-Lipschitz embeddings

Toward the Hilbert-space Lang--Plaut doubling embedding problem, this package constructs moving-window injective Hilbert cocycles on the Engel group whose finite balls are uniformly doubling, admit an exact logarithmic gauge comparison, and incur distortion at least $c\sqrt{k}$ against a fixed homogeneous Engel gauge.

## Boundary

This provides the finite-ball cocycle construction and homogeneous-gauge distortion lower bound, but does not yet exclude arbitrary non-homogeneous Euclidean embeddings; the Hilbert-space Lang--Plaut problem remains open.
