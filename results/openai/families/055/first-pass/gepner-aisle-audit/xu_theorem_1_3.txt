The source defines
  mu_H(F) = H^(n-1) ch_1(F) / (H^n rk(F)),
  xi_H(F) = H^(n-2) ch_2(F) / (H^n rk(F)).

"Let X ... be a smooth quintic threefold and H := c_1(O_X(1)).
Let F be a torsion-free H-slope-semistable sheaf in Coh(X).
Assume that mu_H(F) in [-1,1]."

The displayed upper bound on xi_H(F), with x=|mu_H(F)|, is:
  -x/2                  for 0 <= x <= 1/4;
  x/2 - 1/4             for x in [1/4,5/13] or [8/13,3/4];
  -3x/20                for 5/13 <= x <= 6/13;
  x/2 - 3/10            for 6/13 <= x <= 7/13;
  23x/20 - 13/20        for 7/13 <= x <= 8/13;
  3x/2 - 1              for 3/4 <= x <= 1.
