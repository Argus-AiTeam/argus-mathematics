usage: jacobian.py [-h] {status,find,browse,inspect,run} ...

Use Jacobian math.find and math.run through an MCP sidecar.

positional arguments:
  {status,find,browse,inspect,run}
    status              report MCP protocol, server version, and tools
    find                search Jacobian's installed operations
    browse              browse operation cards in ID order
    inspect             inspect one exact operation contract
    run                 execute one typed mathematical operation

options:
  -h, --help            show this help message and exit
