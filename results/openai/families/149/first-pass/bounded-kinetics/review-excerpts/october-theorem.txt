"Let C subset Z_{>=0}^d be finite, let R subset C x C be
weakly reversible, and fix positive rate constants in
[the mass-action equation]. For every positive stoichiometric class P there
is a nonempty compact convex set K_P subset P with the following
properties. Every initial point x^0 in P gives a unique global positive
solution, and there is a finite T(x^0)>=0 such that
x(t) in K_P (t>=T(x^0)).
Moreover, K_P is forward invariant."

This theorem fixes the rates. Its displayed transient time depends on
