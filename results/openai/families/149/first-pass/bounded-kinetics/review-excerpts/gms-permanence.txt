Theorem 1.1; Definitions 3.8, 4.1 and 4.2.
Mathematical notation transcribed into ASCII.

Theorem 1.1: "Every strongly endotactic reaction network is permanent."

Definition 3.8: "A tempering is a map kappa : R -> CmpctInt that
assigns to each reaction a nonempty compact positive interval."
CmpctInt is defined there as {[a,b] | 0<a<=b<infinity}.

Definition 4.2: "More generally, a network (S,C,R) is itself persistent
or permanent if for all choices of temperings kappa and invariant
polyhedra P, the resulting mass-action differential inclusion has the
corresponding property."

Definition 4.1 requires a compact subset eventually containing every
trajectory for permanence. Theorem 1.1 assumes strong endotacticity;
it is not a theorem stated for arbitrary weakly reversible networks.
