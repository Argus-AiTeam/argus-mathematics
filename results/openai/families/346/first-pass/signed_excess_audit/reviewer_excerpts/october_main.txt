"For every stationary integral m-varifold V in an open set
U subset R^{m+n}, where m,n >= 1,
    dim_H Sing V <= m-1."

The source defines a regular point by local equality V|W = q|Sigma| for
one embedded minimal submanifold without boundary in W and an integer
q >= 1, including equality of the local support.

"Our proof uses AE's signed-excess theorem and local estimates from its
fitting and frequency arguments."
"The almost-everywhere regularity conclusion itself is not an input:
a set can have zero H^m measure and still have Hausdorff dimension
greater than m-1."

The imported Signed excess theorem fixes Q >= 1 and kappa > 0 in the
stationary-integral normal-cylinder setting, with an available B_4.
Its displayed hypotheses and conclusion are
    tau(B_4) <= d = exp(-T),
    l + sup |z_phys| <= d^kappa,
    integral w d(2M-D-C_Q Lambda) <= d exp(-F_Q(T))
for sufficiently large T, support(w) subset B_1, 0 <= w <= 1, and
Lip(w) <= 1. The source then states "This is [AE, Theorem 3.1]."
For a flat reference it specifies Lambda = 0 and omits the physical
smallness condition. This attribution concerns the printed import, not
an independent proof of signed excess or either main theorem.
