# Statement fidelity: field-shift synchronization combinatorial core

This file documents `Main.lean` for claim `C_FIELD_COMBINATORIAL` in context
`CTX_FIELD_SHIFT`. Every declaration is in namespace `FieldShift`.

## Exact scope

This is the **combinatorial core only**. It is not a Lean formalization of finite
Chevalley-group restriction theory, actual edge module constructions, arbitrary
normalizer realizability, or any manuscript main theorem. Separate
representation-theoretic proofs supplied by the parent audit must justify
applying these arithmetic and abstract finite-group results to actual retained
edges and normalizers. No such application is an assumption or a conclusion of
this Lean source. No novelty or independent review is asserted.

## Arithmetic declarations

* `shift_divisible_of_residue_support`: for every set `E` of integers and all
  integers `h,r,c,k`, if `E` is nonempty, `h` divides `r`, every `x` in `E`
  satisfies `h | x-c`, and for every `x` in `E` there exists `y` in `E` with
  `r | x+k-y`, then `h | k`. This includes arbitrary wraparound representatives,
  arbitrary periods (including zero and negative periods), and arbitrary
  integer shifts. Finiteness of `E` and positivity of `h` are not needed.
  Translation containment suffices; equality of translated supports is stronger.
* `progression_residue`: if `h | t` and `h | r`, then every integer position
  `t0+j*t-q*r` differs from `t0` by a multiple of `h`, for all integers `j,q`.
* `progression_no_wrap`: if `t>0` and `0<=j<b`, then
  `0<=j*t<b*t`. The index hypotheses already force `b>0`.
* `progression_mod_representative`: under those same hypotheses,
  `(j*t) % (b*t) = j*t`. Thus these selected progression positions do not wrap
  before reduction modulo the full period.
* `progression_distinct_mod`: for all integers `b,t,i,j`, if `t` is nonzero and
  `0<=i,j<b`, then `i*t` and `j*t` are congruent modulo `b*t` if and only if
  `i=j`. In particular this covers all positive integer `b,t`. Together with
  the preceding two declarations, this is the support noncollision/no-carry
  statement: assigning one digit to each selected position never assigns two
  digits to the same position. It does not assert a representation-theoretic
  tensor-factor decomposition or a theorem about arbitrary overlapping sums.
* `odd_doubling_modEq_iff`: for every odd natural `b` and all natural `i,j`,
  congruence of `2*i` and `2*j` modulo `b` is equivalent to congruence of `i`
  and `j` modulo `b`. This is a universal cancellation statement, not an
  enumeration of tested moduli.
* `odd_doubling_distinct_mod`: consequently, for all `i,j<b`, congruence of
  their doubled indices modulo odd `b` is equivalent to `i=j`. This includes
  `b=1` and supplies the odd unitary doubling noncollision property.
* `synchronized_differences_add`: for all integers `h,a,a1,s`, the hypotheses
  `h | a1-a` and `h | s-a1` imply `h | s-a`. Identifying one common
  intermediate exponent in the actual representations is outside this source.

## Abstract group declarations and the proved normal form

* `commuting_pair_integer_normal_form`: in any group, if `g,d` commute, every
  element of `Subgroup.closure {g,d}` is `g^m*d^n` for some integers `m,n`.
  This existence is **proved by subgroup-closure induction**, including the
  product and inverse cases. It is not an input hypothesis.
* `commuting_pair_card_le`: in any finite group, commuting `g,d` generate a
  subgroup of cardinality at most `orderOf g * orderOf d`. The proved integer
  normal form supplies a surjection from the product of their cyclic subgroups.
  Mathlib's kernel-checked cyclic-subgroup cardinality theorem then counts
  those subgroups. No bounded normal form is assumed.
* `closure_pair_eq_zpowers_of_power`: in any group, `g^v=d` implies that
  `Subgroup.closure {g,d}` is exactly the cyclic subgroup generated by `g`.
* `field_diagram_group_card_bound`: for every finite group `G`, all `g,d` in
  `G`, and every positive natural `v`, if `g,d` commute, `d^2=1`, and
  `g^v=1` or `g^v=d`, then
  `Nat.card (Subgroup.closure {g,d}) <= 2*v`. In the first branch the preceding
  surjection is counted using `orderOf g<=v` and `orderOf d<=2`. In the second
  branch the subgroup is cyclic and `g^(2*v)=1`. Neither commutativity of the
  ambient group nor faithfulness of an action is required.
