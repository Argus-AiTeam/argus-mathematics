# Rectangular projected-box interpolation: algebraic reduction

## Status and scope

`RectInterpolation.lean` proves the complete polynomial, degree, dimension,
and linear-algebra argument **conditional on the single geometric proposition
`LSRectInterpolation.LatticeFaceSelection`**. It does not prove that proposition
and does not claim an unconditional interpolation result. There are no remaining
algebraic obligations and no `sorry`, `admit`, or new axiom declarations.

The file is standalone, imports `Mathlib`, and does not import or modify
`Main.lean`. All declarations below belong to `LSRectInterpolation`.

## Encoding

- `Z4 = Fin 4 → ℤ`, `C4 = Fin 4 → ℂ`, `C3 = Fin 3 → ℂ`.
- `Poly = MvPolynomial (Fin 3) ℂ`.
- `intBox N` is the finite set of integer vectors satisfying
  `∀ i, 0 ≤ n i ∧ n i < (N : ℤ)`. This is literally \(E_N\).
- `castPoint n i = (n i : ℂ)`.
- `enlargedBox N = intBox (4 * (N - 1) + 1)`.
  `mem_enlargedBox` proves that its upper bound is the inclusive
  `((4 * (N - 1) : ℕ) : ℤ)`.
- `intDot r n = ∑ i, r i * n i`.
- `RectIndex t = ∀ j : Fin 3, Fin (t j + 1)`.
- `monomialRow A N t a n = ∏ j, (A (castPoint n) j) ^ (a j).val`,
  where `n : intBox N`.

Thus rectangular monomial exponents are exactly `0 ≤ α j ≤ t j`, not total
degree bounded exponents. The output space is all complex-valued functions
on the integer box, without identifying or discarding columns.

## Exact sole geometric interface

```lean
def LatticeFaceSelection : Prop :=
  ∀ (N : ℕ), 1 ≤ N →
    ∀ (S : Finset Z4), S.Nonempty → S ⊆ intBox N →
      ∀ (F : Z4 → ℂ), (∃ m, F m ≠ 0) →
        (∀ m ∈ enlargedBox N, F m = 0) →
        ∃ u ∈ S, ∃ (m r : Z4) (k : ℤ),
          r ≠ 0 ∧ intDot r u = k ∧ F m ≠ 0 ∧
            ∀ n ∈ S, intDot r n ≠ k → F (m + n - u) = 0
```

This is a definition of a universally quantified proposition, **not an
axiom**. The final theorems take its proof as an ordinary argument. The
interface has no reference to `A`, polynomials, interpolation, rank, or
determinants, and does not impose additional conditions on `F`.

## End theorem types

```lean
theorem projected_box_monomial_span_of_selection
    (hselect : LatticeFaceSelection)
    (N : ℕ) (hN : 1 ≤ N) (t : Fin 3 → ℕ)
    (ht : ∀ j, 3 * (N - 1) ≤ t j)
    (hdim : (4 * N - 3) ^ 4 < ∏ j, (t j - 3 * (N - 1) + 1))
    (A : C4 →ₗ[ℂ] C3) (hA : Function.Surjective A)
    (c : C4) (hker : ∀ x, A x = 0 ↔ ∃ s : ℂ, x = s • c)
    (hc : LinearIndependent ℚ c) :
    Submodule.span ℂ (Set.range (monomialRow A N t)) = ⊤
```

This is directly usable as the row-spanning premise of a greedy basis
construction, after any desired enumeration of the grid or exponent set.
No rank or nonzero-determinant premise appears.

```lean
theorem rectangular_interpolation_of_selection
    (hselect : LatticeFaceSelection)
    (N : ℕ) (hN : 1 ≤ N) (t : Fin 3 → ℕ)
    (ht : ∀ j, 3 * (N - 1) ≤ t j)
    (hdim : (4 * N - 3) ^ 4 < ∏ j, (t j - 3 * (N - 1) + 1))
    (A : C4 →ₗ[ℂ] C3) (hA : Function.Surjective A)
    (c : C4) (hker : ∀ x, A x = 0 ↔ ∃ s : ℂ, x = s • c)
    (hc : LinearIndependent ℚ c) (y : intBox N → ℂ) :
    ∃ p : Poly, (∀ j, p.degreeOf j ≤ t j) ∧
      ∀ n : intBox N, eval (A (castPoint n)) p = y n
```

Here `hc` is precisely rational linear independence of the four complex
coordinates of `c`; `hker` says that the kernel of `A` is the complex line
generated by `c`. With \(D=3(N-1)\), `ht` and `hdim` are exactly the stated
rectangular numerical hypotheses. The strict inequality is not weakened.

## Proved load-bearing algebra

1. **Exact dimension count.**
   `card_intBox` proves `card (intBox N) = N ^ 4`;
   `card_enlargedBox N hN` proves the enlarged cardinality is
   `(4 * N - 3) ^ 4`.
   `coeff_rectPolynomial` and `rectPolynomial_injective` certify independent
   rectangular monomials. `exists_vanishing_rectPolynomial` uses the
   finite-dimensional evaluation map and rank-nullity, rather than assuming
   a nonzero polynomial. Its specialized theorem is:

   ```lean
   theorem exists_enlargedBox_vanishing_polynomial
       (N : ℕ) (hN : 1 ≤ N) (t : Fin 3 → ℕ) (A : C4 →ₗ[ℂ] C3)
       (hdim : (4 * N - 3) ^ 4 < ∏ j, (t j - 3 * (N - 1) + 1)) :
       ∃ R : Poly, R ≠ 0 ∧
         (∀ j, R.degreeOf j ≤ t j - 3 * (N - 1)) ∧
         ∀ n ∈ enlargedBox N, eval (A (castPoint n)) R = 0
   ```

2. **Integer-lattice Zariski density.**
   `integer_grid_funext` follows from Mathlib's polynomial extensionality
   on products of infinite sets, applied to the embedded integers.
   `linearPolynomial` and `linearPullback` explicitly represent composition
   with `A`. Surjectivity then proves:

   ```lean
   theorem exists_integer_eval_ne_zero
       (A : C4 →ₗ[ℂ] C3) (hA : Function.Surjective A)
       (R : Poly) (hR : R ≠ 0) :
       ∃ m : Z4, eval (A (castPoint m)) R ≠ 0
   ```

3. **Face interpolation, without a geometric assumption.**
   `normal_ne_zero_of_rational_independence` proves
   `normal r c ≠ 0` for every nonzero integer normal.
   A complex-linear right inverse `J` is obtained from surjectivity of `A`.
   `affine_inverse_formula` proves the inverse on the hyperplane:

   ```lean
   J (A x) + ((k - normal r (J (A x))) / normal r c) • c = x
   ```

   `affineCoordinate` gives its coordinate polynomials of total degree at
   most one. `gridFactor` is the normalized product over
   `a ∈ Ico 0 N`, `a ≠ u i`; both its indicator evaluations and degree
   `≤ N - 1` are proved. `facePolynomial` multiplies these factors for
   the three coordinates other than an index `i₀` with `r i₀ ≠ 0`.
   `eq_of_intDot_eq_of_eq_off` proves these three coordinates determine a
   point in the hyperplane. The resulting theorem is:

   ```lean
   theorem face_interpolation
       (N : ℕ) (A : C4 →ₗ[ℂ] C3) (hA : Function.Surjective A)
       (c : C4) (hker : ∀ x, A x = 0 ↔ ∃ s : ℂ, x = s • c)
       (hc : LinearIndependent ℚ c)
       (r : Z4) (hr : r ≠ 0) (k : ℤ)
       (u : Z4) (hu : u ∈ intBox N) (huface : intDot r u = k) :
       ∃ Q : Poly, Q.totalDegree ≤ 3 * (N - 1) ∧
         eval (A (castPoint u)) Q = 1 ∧
         ∀ n ∈ intBox N, intDot r n = k → n ≠ u →
           eval (A (castPoint n)) Q = 0
   ```

4. **Translation and multiplication degree bounds.**
   `translate v p` substitutes `X j + C (v j)`.
   `eval_translate` proves evaluation at `z + v`;
   `degreeOf_translate` proves coordinate degrees do not increase.
   `degreeOf_translate_mul` proves
   `degreeOf j (translate v R * Q) ≤ t j` from the exact respective
   bounds `t j - D` and `totalDegree Q ≤ D`, together with `D ≤ t j`.
   `eval_translated_lattice` checks the sign and orientation:

   ```lean
   eval (A (castPoint n)) (translate (A (castPoint (m - u))) R)
     = eval (A (castPoint (m + n - u))) R
   ```

5. **Annihilator contradiction and actual interpolation.**
   `annihilator_contradiction_of_selection` takes arbitrary nonzero weights
   on the box annihilating all polynomials of the required degrees.
   Their nonzero support is the selector's `S`. For its selected `m,u,r,k`,
   the polynomial `translate (A (castPoint (m - u))) R * Q` has the
   required degree. Off-face terms vanish by selection; other on-face
   terms vanish by `Q`; the remaining sum is `w u * F m ≠ 0`.
   `bounded_evaluation_mem_monomial_span` proves the needed passage from
   bounded polynomials to the monomial row span. Dual separation proves
   that span is top. Finally a finite linear combination of these rows
   constructs `rectPolynomial b`, interpolating every prescribed `y`.
