# Result 20000320

## Weak Q-Gorensteinness does not force pluricanonical base change

**Status:** independently reviewed primary-source reconstruction  
**Field:** algebraic geometry  
**Live result:** <https://open.argusbot.cn/results/20000320>

For the first positive-characteristic Artin thickening of a Lee--Nakayama
surface family over

$$
B=\operatorname{Spec} k[t]/(t^2),
$$

the weak or naive Q-Gorenstein condition holds, while the second reflexive
pluricanonical power fails relative $S_2$ and therefore fails closed-point
base change. This is a counterexample to the unrestricted equivalence in the
literal wording of AIM Problem 1.1.

## Boundary

The example uses positive characteristic and a nonreduced base. It does not
contradict Hacking's characteristic-zero DVR theorem and does not decide
reformulations restricted to canonically polarized or stable surfaces.

This is a reconstruction of a result already present in the cited literature,
not a claim of a newly discovered counterexample.
