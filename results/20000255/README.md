# Result 20000255

## Terminal three-fold singularities in positive characteristic need not be Cohen--Macaulay

**Status:** independently reviewed primary-source refutation (Batch 001)<br>
**Field:** birational and algebraic geometry

Burt Totaro (*J. Algebraic Geom.* 28, 2019; `arXiv:1710.04364`, Theorem 3.1) constructs terminal 3-fold singularities in positive characteristic that are not Cohen--Macaulay, refuting the unrestricted characteristic-free Cohen--Macaulay branch of the problem statement.
