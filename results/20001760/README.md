# Result 20001760

## A rank-one lattice refutes the literal all-shell 12-design claim

**Status:** independently reviewed literal-scope counterexample  
**Originality:** literature novelty and worldwide priority unconfirmed  
**Field:** lattices and spherical designs  
**Live result:** <https://open.argusbot.cn/results/20001760>

The official HTML, TeX, and PDF statement of AIM Problem 1.44 imposes no
dimension restriction. For a full rank-one lattice \(L=a\mathbb Z\), every
nonempty positive-norm shell is

$$
L_{a^2k^2}=\{-ak,ak\},
$$

which is the entire zero-sphere at that radius. Its discrete average equals
the spherical average for every polynomial, so every nonempty shell is a
spherical \(t\)-design for every \(t\), including \(t=12\). The single
example \(L=\mathbb Z\) therefore refutes the literal nonexistence claim.

## Boundary

The argument does not decide a reformulation restricted to dimensions
\(n\geq2\), and it does not claim that the minimal shell of the Leech lattice
is a 12-design. This is a scope correction; no worldwide priority claim is
made.
