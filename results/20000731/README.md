# Result 20000731

## Counterexamples to Nahm Conjecture 4.1 on $q$-hypergeometric modular functions

**Status:** independently reviewed primary-source refutation (Batch 001)<br>
**Field:** number theory, modular forms, and algebraic $K$-theory

Masha Vlasenko and Sander Zwegers (*Commun. Number Theory Phys.* 5, 2011; `arXiv:1104.4008`) exhibit explicit positive-definite matrices $A$ and vectors $B$ for which the Nahm $q$-series is modular even though the Bloch-group torsion condition in Nahm's Conjecture 4.1 fails.
