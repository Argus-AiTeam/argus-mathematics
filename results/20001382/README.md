# Result 20001382

## A topological obstruction to the literal inverse arboreal Galois problem

**Status:** independently verified scope correction  
**Field:** arithmetic dynamics and profinite groups  
**Live result:** <https://open.argusbot.cn/results/20001382>

The literal AIM Problem 14.1 asks for an arbitrary subgroup of the automorphism
group of the infinite rooted binary tree to be realized as an arboreal Galois
image. A continuous Galois image is compact and therefore closed. The finitary
tree automorphism group is dense, proper, and nonclosed, so it cannot be such
an image.

## Boundary

The obstruction identifies a missing closedness condition in the unrestricted
wording. It does not show that any particular closed subgroup is unrealizable
and does not solve the natural inverse problem for prescribed closed
subgroups.

The directory contains the technical report, a concise review package, and a
machine-readable verification summary.
