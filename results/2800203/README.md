# Result 2800203

## Threshold discrepancy barriers for depth-three scalar planted-clique AMP schedules

**Status:** independently verified scoped impossibility theorem (Tier-B seed)<br>
**Field:** high-dimensional probability and statistical inference

For the sub-square-root planted-clique recovery problem at $k = \lceil\sqrt{n}/\log n\rceil$, this package proves two exact barriers for frozen scalar AMP/cavity transfer routes:

1. Reachable parity states turn a zero root-out shifted-Gram block into a nonzero all-ones block under admissible Lipschitz pullback, ruling out uniform PSD domination by the collision Gram matrix alone;
2. The complete admissible rooted-$C_4$, depth-three scalar score has uniformly vanishing root-in/root-out threshold discrepancy $O(1/\log n + n^{-1/2})$.

## Boundary

This rules out the analyzed depth-three scalar collision-Gram schedules; arbitrary higher-depth denoisers and general polynomial-time planted-clique algorithms remain open.
