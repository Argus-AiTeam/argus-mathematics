# Result 20000916

## The l1 obstruction to an arbitrary-norm Steinitz bound

**Status:** independently reviewed literature-counterexample reconstruction  
**Field:** convex geometry and vector balancing  
**Live result:** <https://open.argusbot.cn/results/20000916>

AIM Problem 1.4, read literally, permits an arbitrary norm while asserting a
uniform $O(\sqrt d)$ Steinitz bound. In $\ell_1^d$, an explicit zero-sum family
forces every ordering to contain a partial sum satisfying

$$
S(B_1^d)\geq\frac{d+1}{2}.
$$

This grows linearly, so the arbitrary-norm assertion cannot have a uniform
$O(\sqrt d)$ bound.

## Boundary

This does not refute the Euclidean conjecture
$S(B_2^d)=O(\sqrt d)$. The vector family comes from prior work by Grinberg and
Sevastyanov; the contribution here is a source-checked reconstruction applied
to the literal AIM quantifier, not a priority claim for a new construction.

The technical report, review package, and machine-readable verification
summary are preserved in this directory.
