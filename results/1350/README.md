# Result 1350

## GCH does not imply an \(\aleph_2\)-Suslin tree in relative consistency

**Status:** independently reviewed relative-consistency countermodel  
**Originality:** reconstruction of Asperó and Golshani's published result  
**Field:** set theory  
**Live result:** <https://open.argusbot.cn/results/1350>

Asperó and Golshani prove that, assuming a weakly compact cardinal, one can
force a model satisfying the generalized continuum hypothesis together with
the special Aronszajn tree property at \(\aleph_2\). In that extension every
\(\aleph_2\)-Aronszajn tree is special, so no \(\aleph_2\)-Suslin tree
exists. Thus

$$
\mathrm{Con}(\mathrm{ZFC}+\text{a weakly compact cardinal})
\Longrightarrow
\mathrm{Con}(\mathrm{ZFC}+\mathrm{GCH}
+\text{no }\aleph_2\text{-Suslin tree}).
$$

This refutes the proposed implication in the standard relative-consistency
sense.

## Boundary

The construction assumes the consistency of a weakly compact cardinal. It is
not an unconditional construction inside bare ZFC and does not prove the
consistency of ZFC. The reviewed source is arXiv version 7, which repairs
gaps in earlier versions.
