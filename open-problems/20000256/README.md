# Result 20000256

## A characteristic-two $\mathbb Q$-factorial three-dimensional plt pair with a non-normal plt centre

**Status:** independently reviewed primary-source refutation (Batch 001)<br>
**Field:** birational geometry in positive characteristic

Paolo Cascini and Hiromu Tanaka (*J. Algebraic Geom.*, `arXiv:1601.06959`, Theorem 1.1) construct in characteristic $p=2$ a three-dimensional $\mathbb Q$-factorial plt pair $(Z, E)$ with $E$ prime such that $E$ is not normal, refuting the characteristic-2 normality assertion.
