# Result 20000472

## A bounded Fock-space Toeplitz operator with unbounded heat transform at $t=1/4$

**Status:** independently reviewed primary-source refutation (Batch 001)<br>
**Field:** operator theory and harmonic analysis

Shi-Quan Looi (`arXiv:2204.06041`, Theorem 1.1) constructs a measurable symbol on Fock space whose Toeplitz operator $T_f$ is bounded on $F^2(\mathbb C)$, while its Berezin/heat transform at $t = 1/4$ is unbounded.
